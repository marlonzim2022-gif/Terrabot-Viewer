# Terrabot Viewer

Visualizador público dos replays do Terrabot. O treinamento, os modelos e o código principal permanecem no repositório privado.

**Site:** https://marlonzim2022-gif.github.io/Terrabot-Viewer/

## Adicionar as gravações V5

O visualizador está publicado, mas os GIFs precisam ser enviados para a pasta `media/` deste repositório público. Faça upload **somente** dos quatro GIFs abaixo, sem arquivos de treinamento, pesos ou credenciais:

| GIF baixado | Nome no repositório |
| --- | --- |
| `trained.gif` | `v5_original.gif` |
| `trained_seen_layout.gif` | `v5_treino.gif` |
| `trained_unseen_layout.gif` | `v5_inedito_1.gif` |
| `trained_unseen_layout_2.gif` | `v5_inedito_2.gif` |

No navegador do celular, abra `https://github.com/marlonzim2022-gif/Terrabot-Viewer/upload/main/media`, selecione os arquivos com os nomes indicados e confirme o commit. A página do GitHub Pages será atualizada após a publicação automática.

A V5 obteve **0/50** no cenário original e **11/50** em posições inéditas. Os quatro GIFs ilustrativos são tentativas individuais e não representam necessariamente os resultados agregados.

**Nota:** os GIFs mostram o simulador visual PixelWorld, não o Terraria Mobile.
